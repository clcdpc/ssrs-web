# Third-party license texts

These files are third-party license material, not the project's AGPL license. The MIT, Apache-2.0, BSD-2-Clause, and BSD-3-Clause texts are from the [SPDX License List 3.29.0](https://github.com/spdx/license-list-data/tree/v3.29.0/text). The release notice exporter uses them with the copyright metadata from the exact restored NuGet packages.

The Hangfire 1.8.25 license text was copied from its locked NuGet package. The Microsoft SNI license text was copied from `Microsoft.Data.SqlClient.SNI.runtime` 7.1.0. The exporter checks those tracked copies against the restored packages before including them in a publish. Hangfire's upstream `COPYING` and `COPYING.LESSER` are also retained with the vendored SQL installer and administrative setup artifact.
